# RootLearner · 词根背诵

离线单文件英语词根背诵工具：范围乱序翻面学习 → 基本 3 轮选择题测试（错题补考至多 8 轮）→ 艾宾浩斯间隔复习。
一个 `.html` 文件，双击即用：无服务器、无网络、零依赖，手机电脑都能用。

词库规模：342 个词根组 / 819 个单词 / 17 个字母段（A–R，无 K）。

## 项目背景与目标

- **为谁解决什么问题**：为我自己（及有同类需求的学习者）背诵英语词根与派生词。原有方式是纸质词根表和自制的旧 Qt 程序（Windows exe），既不能乱序背诵、多轮自测，也没有间隔复习，且无法在手机上使用。
- **已完成功能**：字母范围与每日数量选择、范围内乱序背诵、翻面卡片学习、6 种题型四选一测试、基本 3 轮 + 错题补考（上限 8 轮）、艾宾浩斯间隔复习（1/2/4/7/15/30 天）、复习计划看板、学习记录、按范围/全部两级进度重置。
- **怎样判断功能完成**：`tests/test.mjs` 73 项无头断言全绿（覆盖正常流程、轮数边界、存储异常等），并以 headless Chrome 渲染成品截图人工核对（见 `docs/`）。

## 课程知识与核心设计

课程：《计算概论（B）》2026 秋（[课程仓库](https://github.com/GMyhf/2026fall-cs101)）。本项目用到并可以解释的课程知识：

**数据结构**

- **记录表 `DB.rec`**：以词根 id 为键的普通对象，近似哈希表——任意词根进度的查、改均 O(1)；若用数组存记录，每次查询需 O(N) 扫描（N=342，且每轮渲染多次调用）。
- **乱序池 `DB.orderPool`**：数组存选定范围的一个完整随机排列（空间 O(N)），持久化到 localStorage，保证"乱序"跨会话稳定；`ensureOrder()` 用 Set 做 O(N) 完整性校验，范围变化或重置时重新生成。
- **Set 去重/校验**：选项去重（`uniqueOpts()`，小写归一化）、乱序池完整性校验、今日批次新词与到期复习的并集去重，均为 O(N)。

**算法**

- **Fisher-Yates 洗牌**（`shuffle()`，O(n) 均匀乱序）：乱序池生成、每轮题目顺序、选项顺序三处复用。
- **间隔复习调度**：掌握等级 level∈[0,6] 映射间隔表 `INTERVALS=[1,2,4,7,15,30]`；会话结束 `commit()` 统一结算——本次全对则 level+1 且 `next = 今天 + INTERVALS[level-1]`，答错过则 level 归零、明天重来。复习队列 `dueList()` 为 `next <= 今天` 的 O(N) 过滤；复习计划按未来 7 天分桶 O(N)。选择"会话级结算"而非每题即时更新，是为了保证"一次测试 = 一次调度决策"，避免中途错题造成等级抖动。
- **状态机**：页面 `view ∈ {home, session, plan, records}`，会话内 `phase ∈ {study, quiz, roundend, done}`；轮次推进条件集中在 `mustContinue()` / `canContinue()` 两个函数（基本轮数未满必须继续；考满后仅有错题且未达上限才追加），避免条件散写——历史上"条件散写"曾导致"全对时第 1 轮就结束"的真 bug。
- **干扰项采样**：优先取同字母段其他词根（`otherRoots()`），不足 6 个退回全库，兼顾干扰性与可答性。
- **安全**：所有词库文本经 `esc()` 做 HTML 转义后再拼入 `innerHTML`，防止数据中特殊字符造成注入。

**复杂度与取舍分析**

- `byId()` 是对 `DATA.roots` 的 O(N) 线性查找；建 id→root 的 Map 可 O(1)，但 N=342 且单次渲染调用次数少，保留数组使数据结构更简单——这是有意识的取舍，不是疏漏。
- **单文件 vs 模块化**：产品形态要求"双击即用、零安装"，因此构建脚本把词库与逻辑内联进单个 HTML；核心逻辑与界面的分离在文件内以三层实现——纯逻辑层（数据访问、题型生成、会话结算，不触 DOM）、渲染层（`xxxHtml()` 字符串拼装）、事件委托层（单一 click 监听 + `data-*` 属性）。`tests/test.mjs` 从构建产物抽出真实脚本、在假 DOM 中无头运行并点击真实渲染出的按钮，即逻辑层可脱离浏览器独立测试的证明。

## 安装与运行

**使用（无需任何环境）**

1. 双击仓库根的 `root-learner.html`（或中文副本 `词根背诵.html`），任意现代浏览器（Chrome / Edge / Firefox / Safari）打开即用。
2. 首页选字母范围与每日数量 → 「开始今日学习」→ 翻面学习 → 自动进入多轮测试 → 结束后按艾宾浩斯间隔排入复习计划。

**构建与测试（仅开发者需要；成品本身不依赖 Node）**

- 环境：Node.js >= 16，零第三方依赖。
- 构建：`npm run build`（即 `node build.mjs`）——读取 `src/template.html` 与 `src/vocab.json`，注入数据并做构建期语法自检，产出 `root-learner.html`。
- 测试：`npm test`（即 `node tests/test.mjs`），期望输出 `===== 结果：73 passed, 0 failed =====`。

**注意**：学习进度存于浏览器 localStorage，按文件**完整路径**隔离——改名、移动目录或换浏览器即为全新进度；同目录两份 html 副本的进度互相独立。

## 测试与结果

`node tests/test.mjs`：**73 passed, 0 failed**（Node v24 实测）。

原理：不 mock 业务逻辑——从构建产物 `root-learner.html` 抽出真实 `<script>`，用 `node:vm` 在假 DOM / 假 localStorage 中执行，通过点击真实渲染出的按钮（按 `data-*` 属性查找）驱动完整流程。

| 分组 | 覆盖内容 |
|---|---|
| 范围乱序 | 顺序持久化（重复打开不变）、池无重复无遗漏、不等于原序、换范围/手动重排、每日新学按乱序抽取 |
| 测试轮数 | 全对恰好考满 3 轮、第 1–3 轮均考全部卡片、第 3 轮有错追加第 4 轮且只考错题、补考再错继续追加、每轮全错最多 8 轮停止、每轮题序重新乱序 |
| 进度重置 | 记录与等级/错次结算、按范围重置只清范围内且范围外保留、重置后重新乱序、清空全部、两处入口存在 |
| 功能回归 | 6 题型均 4 选项且含正确答案且互不重复、范围/每日数量控件、标题统计、键盘流（空格翻面、方向键切换、数字答题） |
| 复习计划 | 3 轮全对后等级=1（间隔 1 天）、计划页/记录页渲染 |
| 边界与异常 | localStorage 内容损坏回退默认、localStorage 被禁用降级内存并提示、起始字母>结束字母按字母序纠正、每日数量 0/5000 钳制到 1/999 |

界面验证：headless Chrome 渲染真实成品后人工核对截图（`docs/`）；目录重组后重新构建的产物 sha256 与重组前逐字节一致。

## 局限与改进

- 词库仅覆盖 A–R 的词根部分：无 K 字母、无 S–Z、无前缀/后缀——这是数据来源的天然边界，不是程序缺陷。
- 词根无中文释义（题型 1/2 为词根 ↔ 英文释义）。
- 进度仅存本浏览器 localStorage：无跨设备同步、无导出/导入，清理浏览器数据会丢失。
- 中途退出会话不保存测试结果（卡片记为"已学未测"，次日进入复习队列）。
- "今日新学完成前不学新词"为软引导（仍可点「只学新词根」跳过复习），未做硬拦截。
- 无独立错题本页面（错题仅在轮次小结列出）。
- 后续计划：进度导出/导入（JSON）、错题本、补全词库、补考轮独立升级策略。

## 数据来源

- `src/vocab.json`（342 词根组 / 819 单词 / 17 字母段）由自备 `data.txt`（826 行，7 字段：字母=编号=词根变体=英文释义=单词=中文释义=词性）解析清洗而来；该数据来自本人旧自制 Qt 背诵程序。
- 清洗规则：`\u00a0`→空格、多空格折叠、中英文逗号空格规范化。
- 另有原始素材《Roots, Prefixes and Suffixes (2026)》PDF（45 页），其文本提取结果含 OCR 噪声，**未采用**。
